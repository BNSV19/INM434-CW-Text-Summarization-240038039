## Google-Colab-Notebooks
There are 4 notebooks and are as follows:

1. NLP_Bart-Baseline.ipynb: Contains the baseline model as refered to in the report.
2. NLP_Bert-Summarization_Final.ipynb: Contains the code used for Experiment 1,2 and 3.
3. NLP_Bart-Summarization_Detailed-Model-Evaluation.ipynb: Contains the code to load a model and evaluate the performance metrics of the same.
4. NLP_Bart-Summarization_Sample-Model-Prediction.ipynb: Contains the code to load a model and generate the output of sample inputs.

## Model_Runs
There are 3 models saved here:

1. Bart-Summarisation-Final-1.pth: Model weights of BART trained for Experiment 1, used entire dataset for training.
1. Bart-Summarisation-Final-2-test.pth: Model weights of BART trained for Experiment 2, used 10000 samples for training.
1. Bart-Summarisation-Final-3.pth: Model weights of BART trained for Experiment 3, used entire dataset for training.
